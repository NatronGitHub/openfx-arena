# The plug-ins of Arena.ofx.bundle, rendered by tests/hostdemo/run.cmake with openfx's
# hostDemo, once (t=0), with their default parameters and hostDemo's default PAL SD inputs.
# Every plug-in of the bundle, each major version, must have a line (the test fails otherwise):
#   <identifier> <major version> <context> [hostDemo arguments]
#   skip <identifier> <major version> <reason>
# A plug-in may have more lines (each one is rendered too), e.g. with edge-case values.
# @SAMPLES@ is the directory of the generated sample files (make_samples.cpp, sample.svg).
# hostDemo has filter and general contexts only: readers are rendered in the general context.

# Auto size with a stroke, which the version 7 RoD fits (#135)
net.fxarena.openfx.Text 7 filter -s autoSize=1 -s strokeSize=4
net.fxarena.openfx.Text 6 filter -s autoSize=1 -s strokeSize=4
skip fr.inria.openfx.ReadCDR 1 no CorelDRAW sample: libcdr only reads them, and a hand-written .cdr is not simple

net.fxarena.openfx.ReadSVG 3 general -s filename=@SAMPLES@/sample.svg
